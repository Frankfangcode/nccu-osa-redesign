# 資訊架構（IA）

## 原則
- **第一層：任務導向**「我想…」——學生用動詞找服務，不需要先知道組織分工。
- **第二層：單位導覽**——已知道要找哪個組的人，從「單位」進入；每個單位頁反向連回它負責的任務。
- **緊急求助**不屬於任何一層：全站頂部紅色橫條、頁首按鈕、頁尾、每個單位頁側欄都有，號碼只在 `src/data/site.ts` 的 `emergency` 維護一次。

## 站點地圖
```
/                     首頁：搜尋、我想…（6 個熱門任務）、依身分、最新消息、不知道找誰、單位目錄
/tasks/               我想…（全部任務）
/tasks/{slug}/        任務頁：步驟、相關連結、負責單位、聯絡電話、相關服務
/units/               單位總覽
/units/{slug}/        單位頁模板：常用服務 → 最新公告 → 聯絡 → 緊急 → 其他單位
/news/                消息列表：依單位、類別篩選（可用 ?unit= ?cat= 帶參數）
/search/              服務搜尋：任務＋單位服務項目＋單位，瀏覽器端即時搜尋
/emergency/           緊急求助：依「情境」分區，而非依單位
```

## 任務 ↔ 單位對照
| 任務（我想…） | 負責單位 |
|---|---|
| 申請宿舍 | 住宿輔導組 |
| 找獎學金（含減免、就貸） | 生活事務暨僑生輔導組 |
| 請假 | 生活事務暨僑生輔導組 |
| 預約諮商 | 身心健康中心 |
| 看病或處理傷口 | 身心健康中心、學安中心 |
| 辦社團活動 / 借場地 | 課外活動指導組 |
| 找實習或工作 | 職涯發展中心 |
| 在校外租屋 | 住宿輔導組、學安中心 |
| 申請急難救助 | 生活事務暨僑生輔導組 |
| 辦僑生／陸生事務 | 生活事務暨僑生輔導組 |
| 緊急求助 | 學安中心、身心健康中心 |

## 資料狀態（重要）
本專案的 cloud 環境無法連線 `osa.nccu.edu.tw`，因此：
- 單位名稱、服務項目、電話：整理自公開搜尋結果（原站舊頁面快取、校安流程圖 PDF），全部標記 `verified: false`。
- 任務的「相關連結」暫時都指向原站首頁。
- 消息為版面示範用的範例資料（`sample: true`）。
- 單位清單可能不完整（例如原住民族學生資源中心、資源教室是否歸學務處，尚未確認）。

**待辦**：開放網路後，爬取原站選單與各組頁面，以實際資料取代 `src/data/site.ts`，並核對每一支電話。
